# Мой шкаф

Гардероб с описанием каждой вещи и конструктор образов. Выбираешь одну вещь — в остальных блоках остаются только те, что к ней подходят. Дизайн в стиле iOS 26: стекло поверх размытого фона, светлая и тёмная тема, одна вёрстка для телефона и компьютера.

## Структура

```
index.html        разметка: три раздела — «Образ», «Гардероб», «Правила»
css/app.css       дизайн-система: токены, стекло, компоненты, анимации
js/data.js        все вещи гардероба и правила (менять вещи — только здесь)
js/app.js         логика конструктора и интерфейса
tools/build.py    собирает всё в один файл dist/moy-shkaf.html
dist/             готовый однофайловый вариант (можно отправить в мессенджер)
```

## Как опубликовать на GitHub Pages

1. Создай репозиторий на github.com (например, `moy-shkaf`).
2. Загрузи туда содержимое этой папки (кнопка «Add file → Upload files» или `git push`).
3. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)` → Save.
4. Через минуту сайт появится по адресу `https://<логин>.github.io/moy-shkaf/`.

## Как добавить или поменять вещь

Открой `js/data.js` и добавь строку в массив `I`:

```js
{id:"newShirt", n:"Название", slot:"top", cat:"shirt", s:"SM", f:[1,2], d:"Что это за вещь.", w:"Как носить."},
```

- `slot` — куда встаёт вещь: `bottom`, `top`, `layer`, `shoes`, `bag`, `belt`, `acc`
- `s` — сезоны: `S` жара, `M` +10…19, `C` холод
- `f` — нарядность от 0 (спорт) до 3 (вечер), диапазон `[от, до]`
- флаги по необходимости: `dark` (тёмный низ), `brown` (коричневая обувь), `loud` (яркий акцент), `pat` (узор), `wide`, `mini`, `belt` и др. — описаны в первой строке файла

После правки данных пересобери однофайловую версию: `python3 tools/build.py`.

## Дизайн-система

| Токен | Светлая | Тёмная | Где |
|---|---|---|---|
| `--bg` | #EEF0F3 | #0F1114 | фон под пятнами |
| `--glass` | белый 58% | графит 55% | стеклянные панели, blur 28px |
| `--tint` | #3E6491 | #9DB9DA | всё, что нажимается |
| `--ink` | #1C1C1E | #F2F2F7 | выбранная вещь |
| `--ok` | #3D7A55 | #8FD0A5 | «Образ готов» |

Шрифт — системный (SF Pro на Apple, Roboto на Android). Радиусы 28/22/16/12 px и «пилюли». Движение: 0.18 с на нажатие, 0.28 с на появление и скрытие, 0.42 с на лист «Твой образ»; при включённом «Уменьшить движение» анимации отключаются.
